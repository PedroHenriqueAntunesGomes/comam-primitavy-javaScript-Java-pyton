Os tipos de Java primitivos são:

. Byte - Ocupa 8 bits. Guarda números de -128 a 127;
. Short - Ocupa 16 bits. Guarda números de -32.768 a 32.767;
. Int - Ocupa 32 bits (4 bytes). É o padrão para números inteiros;
. Long - Ocupa 64 bits. Guarda números inteiros muito grandes (usa um L no final);
. Float - Ocupa 32 bits (precisão simples, usa um f no final);
. Double - Ocupa 64 bits (precisão dupla, padrão para decimais);
. Char - Ocupa 16 bits. Guarda um único caractere em formato Unicode (usando aspas simples);
. Boolean - Ocupa 1 bit. Guarda apenas valores lógicos verdadeiro (true) ou falso (false).

Exemplos:
//3. Byte (serve para armazenar números de -128 a 127)
byte idade = 18
System.out.println(idade)

//4. Short (serve para armazenar números de -32.768 a 32.767)
short cota = 1800
System.out.println(cota)

//5. Int (É o padrão para números inteiros)
int populacao = 58000
System.out.println(populacao)

//6. Long (Guarda números inteiros muito grandes)
long distancia = 1500000000L;
System.out.println(distancia)

//7. Float (precisão simples, usa um f no final)
float nota = 7.5f
System.out.println(nota)

//8. doble(precisão dupla, padrão para decimais)
doble preco = 29.92;
System.out.println(preco)

//9. Char(Guarda um único caractere em formato Unicode (usando aspas simples))
char tipo sanguineo = 'O'
System.out.println(tiposanguineo)

//10. Boolean (Guarda apenas valores lógicos verdadeiro (true) ou falso (false))
boolean aprovado = true
System.out.println("Status do aluno: " + aprovado)

OBS: 1. Precisão Simples (float)Espaço: Usa 32 bits (4 bytes) de memória.Capacidade: Garante precisão de 6 a 7 casas decimais.
Uso: Ideal para economizar memória em grandes arrays ou em sistemas com hardware muito limitado, onde pequenas variações decimais não importam 
(ex: coordenadas de gráficos 3D ou sensores simples).Sintaxe Java: Exige a letra f no final do número (float nota = 7.5f;).
2. Precisão Dupla (double)Espaço: Usa 64 bits (8 bytes) de memória (o dobro do float).Capacidade: 
Garante precisão de 15 a 17 casas decimais. Uso: É o padrão no Java para qualquer número com ponto decimal. 
Usado na maioria dos cálculos matemáticos comuns, física e estatística.Sintaxe 
Java: Não exige letra no final (double preco = 19.99;).
